The browser's legacy nRF52 DFU implementation follows Adafruit's published
SLIP/HCI serial DFU protocol and the implementation in MeshCore Open:
  https://github.com/adafruit/Adafruit_nRF52_nrfutil
  https://github.com/mikecarper/meshcore-open
  MeshCore Open: Copyright (c) 2025 zjs81, MIT.
Cross-checked with the official MeshCore browser flasher (MIT):
  https://github.com/meshcore-dev/flasher.meshcore.io
  Copyright (c) 2025 Rastislav Vysoky.
The ESP32-S3 watchdog reset sequence follows the public Espressif esptool
target register definitions; esptool is licensed GPL-2.0-or-later.

The exact repository Python validators are distributed unmodified and run
locally in WebAssembly. No device credentials, backups, or local-helper
process are included in the static site.

Complete runtime license texts and package attribution are generated into
the licenses/ directory at build time. Source and build instructions are
available at the repository link above; no modifications to third-party
runtime packages are made by this application.
