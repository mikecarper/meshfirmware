USB reconnect trouble · virtual machines & older firmware

If the bootloader port disappears, pause VMs configured for USB auto-capture, or disable that radio's automatic VM passthrough before retrying. A VM may claim the newly enumerated ROM/DFU device; do not assume it will be returned after 30 seconds. The page cannot reclaim USB from a VM or restart a Windows driver. Re-select the same radio after the host regains it.

Some older ESP32 TinyUSB firmware stalls during bootloader entry on a direct Windows root USB port. A USB hub or another port routed through an internal hub can help. No administrator CLI command is part of the browser workflow. Never interrupt an active partition-migration bridge merely because it temporarily disappears.

Full Companion text mode

Use only for a running Full Companion in text mode. Binary handoff may turn USB logging off. nRF52 flashing uses its serial DFU port, not a mounted drive.

nRF52 erase & DFU options

The final image is validated before erase. Wipe requires its own acknowledgement, separate from a board override. After erase, select the same physical radio’s DFU serial interface; no mounted drive is used.

Preview status & browser limitations

Hardware preview · Protocol, validation and simulated USB tests pass; live-device flashing and browser persistence have not yet been verified. Use a recoverable bench device first.

Direct on this page

ESP32 write-only updates, merged installs, explicit-offset components, chip/MAC/security checks and target MD5 readback; legacy Adafruit nRF52 application/bootloader/SoftDevice serial DFU ZIPs (no drive needed); UF2 copying for other supported boards; MeshCore companion backup/restore and script JSON import; CommonCLI partial snapshots; reviewed ESP32/C3/S3 USB partition migration.

Requires your permission

Use desktop Chrome or Edge with Web Serial. Port selection, reconnects and downloads remain explicit. CH340 and other UART bridges use the OS serial driver; the page cannot install it or change Raspberry Pi USB speed. Firmware hosts may require Download → local file because of CORS.

Explicit limitations

No automatic CommonCLI restore or unreviewed partition migrations. Unstructured optional CLI snapshots remain for manual comparison. Backups are logical, not whole-flash or wipe-safe images. A completed transfer is not proof of application startup.
